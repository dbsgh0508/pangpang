# 팡팡주얼리

쥬얼리 판매 사이트 (상품 목록 · 검색 · 질문 답변 · 문자/전화 문의)

## 파일 구성
- `팡팡주얼리-v2.html` : 사이트 본체 (상품 목록, 번호 배치, 상품 정보)
- `qa.js` : 질문·답변 데이터 (문의하기에서 고객 질문에 맞는 답을 찾아 보여줌)
- `images/` : 상품 사진·GIF 폴더
- `vercel.json` : 주소창에 `/`만 쳐도 사이트가 열리도록 설정

## 상품 등록
`팡팡주얼리-v2.html` 안의 `EXAMPLES`에서 번호(001~150)별로 이름을 채웁니다.
- `name` : 상품명 (비워두면 "준비중"으로 보임)
- `image` : 사진/GIF 경로 (예: `images/002.gif`)
- `desc`, `material`, `tags` : 설명, 소재, 검색 키워드
- `soldOut` : `true`면 품절

## 질문·답변 추가
`qa.js`의 `QA` 목록에 항목을 추가합니다.
- `keywords` : 고객 질문에 들어가면 매칭되는 핵심 단어
- `alts` : 고객이 비슷하게 묻는 문장 예시 (많을수록 정확)
- `productId` : 특정 상품 전용이면 번호 (예: `"002"`), 없으면 모든 상품에 보임

## 배포
GitHub 저장소에 파일과 `images` 폴더를 올린 뒤, Vercel에서 해당 저장소를 Import하면 됩니다.
