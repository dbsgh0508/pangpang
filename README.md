# 팡팡주얼리

쥬얼리 판매 사이트 (상품 목록 · 검색 · 문자/전화 문의)

## 상품 등록
`팡팡주얼리-v2.html` 파일의 `PRODUCTS` 목록에 상품 객체를 추가합니다.

- `category`: 목걸이 / 반지 / 팔찌 / 귀걸이
- `image`: 사진 주소 (비워두면 "사진 준비중" 표시)
- `soldOut`: `true`면 품절 처리

## 배포
GitHub 저장소에 올린 뒤 Vercel에서 해당 저장소를 Import하면 됩니다.
`vercel.json`이 `/` 접속 시 `팡팡주얼리-v2.html`을 보여줍니다.
